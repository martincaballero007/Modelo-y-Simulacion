1. Justificación de Distribuciones (G/G/c/K)

Los arribos de consultas backend son independientes y se modelan con un proceso de Poisson (tiempos entre llegadas exponenciales de media 1/λ). La duración SQL sigue por defecto una Lognormal (cola pesada: consultas indexadas rápidas y JOINs complejos ocasionales), con cola finita K que modela el connection timeout.

2. Análisis del Cuello de Botella (As-Is)

Con c = 5 conexiones y servicio medio de 50 ms (μ = 20 req/s por conexión), la capacidad máxima es 100 req/s. Al subir el tráfico a 92 req/s (E1) o 115 req/s (E2), ρ supera el 90 %, disparando Wq de forma no lineal, saturando el búfer K = 40 y generando rechazos HTTP 503.

3. Recomendación de Rediseño (To-Be)

Escalar el pool de 5 a 8 conexiones (E3) absorbe 92 req/s con utilización segura (~58 %), cero rechazos y cumplimiento de SLA superior al 94 %, sin sobredimensionar memoria en el motor de base de datos.

import math, random, statistics, simpy

def correr_replica_simpy(lam, c, media_s=0.05, dist="lognormal", k_max=40, t_sim=60.0, warmup=6.0, seed=42):
    rng = random.Random(seed)
    env = simpy.Environment()
    pool = simpy.Resource(env, capacity=c)
    t_prev, en_cola, en_srv = 0.0, 0, 0
    area_q, area_s = 0.0, 0.0
    wq_list, w_list = [], []
    llegadas, rechazos = 0, 0

    def acumular():
        nonlocal t_prev, area_q, area_s
        ahora = env.now
        ini = max(t_prev, warmup)
        if ahora > ini:
            dt = ahora - ini
            area_q += en_cola * dt
            area_s += en_srv * dt
        t_prev = ahora

    def gen_servicio():
        if dist == "exponencial": return rng.expovariate(1.0 / media_s)
        if dist == "normal": return max(0.005, rng.gauss(media_s, media_s * 0.25))
        if dist == "uniforme": return rng.uniform(0.5 * media_s, 1.5 * media_s)
        sigma_ln = math.sqrt(math.log(1 + 0.8**2))
        mu_ln = math.log(media_s) - 0.5 * sigma_ln**2
        return rng.lognormvariate(mu_ln, sigma_ln)

    def peticion():
        nonlocal en_cola, en_srv, llegadas, rechazos
        t_ll = env.now
        medida = t_ll >= warmup
        if medida: llegadas += 1
        if en_cola >= k_max:
            if medida: rechazos += 1
            return
        acumular(); en_cola += 1
        with pool.request() as req:
            yield req
            t_ini = env.now
            acumular(); en_cola -= 1; en_srv += 1
            yield env.timeout(gen_servicio())
            acumular(); en_srv -= 1
            if medida:
                wq_list.append(t_ini - t_ll)
                w_list.append(env.now - t_ll)

    def generador():
        while True:
            yield env.timeout(rng.expovariate(lam))
            env.process(peticion())

    env.process(generador())
    env.run(until=t_sim)
    acumular()
    t_med = t_sim - warmup
    return {
        "Wq_ms": statistics.mean(wq_list) * 1000,
        "W_ms": statistics.mean(w_list) * 1000,
        "rho": (area_s / (c * t_med)) * 100,
        "Lq": area_q / t_med,
        "L": (area_q + area_s) / t_med,
        "rechazo_pct": 100 * rechazos / max(1, llegadas)
    }
